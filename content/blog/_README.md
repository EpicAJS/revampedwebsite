# Blog posts

Files starting with `_` are ignored, so this file never publishes. Use that
prefix for drafts too: `_half-finished-thought.md` stays private.

One Markdown file per post. The filename becomes the URL slug, so
`shipping-rl-infra.md` is served at `/blog/shipping-rl-infra`.

Front matter:

```markdown
---
title: "Shipping RL infrastructure at scale"
date: "2026-09-18"
excerpt: "One sentence that shows up in the track list."
tags: ["infra", "rl"]
---

Your post body in Markdown.
```

Read time is calculated from the word count and shown as the track duration.
Posts sort newest first. With no posts here, the Blog section hides itself
everywhere on the site.
